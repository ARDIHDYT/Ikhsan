# 🏡 3D Interactive Modern Smart House Simulation
### Rumah Modern - Peliharaan Macan, Kanopi Samping & Auto Mode

🌐 **Live Demo Website**: [https://ardihdyt.github.io/Ikhsan/](https://ardihdyt.github.io/Ikhsan/)

---

## 🌟 Fitur Utama Simulasi 3D
1. **Interactive 3D Modern Architecture (Three.js)**:
   - Desain arsitektur rumah modern lengkap dengan eksterior dan interior interaktif.
   - Kanopi samping otomatis (*smart retractable canopy*).
   - Animasi peliharaan macan (*pet tiger*) interaktif.
   - Siklus pencahayaan siang & malam (*day/night dynamic lighting*).

2. **Floating Dashboard Control**:
   - Kontrol lampu, pintu, kanopi, dan fitur otomasi rumah pintar (*smart home auto mode*).
   - Navigasi kamera preset (orbit, view depan, interior, kanopi).

3. **Standalone Single-File Web Application**:
   - Dibuat dengan Three.js dan JavaScript murni.
   - Langsung dapat dijalankan di browser apa saja tanpa instalasi tambahan.

---

## 🚀 Cara Menjalankan Secara Lokal
Buka file `index.html` langsung di browser favorit kamu (Google Chrome, Microsoft Edge, Firefox, Safari).
